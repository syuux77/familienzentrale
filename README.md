# Familienzentrale

Familien-Dashboard als Web-App für ein Wandtablet (iPad im Flur) und die Handys der Eltern.

- Daten: Google-Tabelle „Familienzentrale – Daten“, angebunden über ein Google Apps Script (Web-App).
- Zugriff nur mit dem Familien-Schlüssel. Der Schlüssel steht **nie** in diesem Repository; jedes Gerät bekommt ihn einmalig über einen Einrichtungs-Link (`…/#key=…`).
- Stand: Technik-Test mit dem Haushalt-Modul (`/haushalt/`).
